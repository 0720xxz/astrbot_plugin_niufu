# SCP:SL 服务器查询 for AstrBot

> 支持多组别管理、多服务器状态查询、IP端口映射、历史趋势、告警推送、服务器搜索等

## 主要功能

- **服务器查询**：`/查服` `/牛服` `/鸽服` 查看各组在线人数
- **IP端口**：`/ip` 获取服务器公网连接地址
- **详情卡片**：`/详情` 查看单个服务器的完整信息（版本、插件、介绍等）
- **服务器搜索**：`/搜索` 从全网搜索包含关键词的服务器
- **IP反查**：`/查IP` 按IP查找对应的服务器
- **历史趋势**：`/历史` 渲染折线图展示在线人数变化
- **定时统计**：`/统计` 查看日/周/月统计数据
- **告警推送**：人数暴跌或离线时自动推送告警（支持撤回）
- **多源兜底**：三路数据源（scplist.kr + scpslgame + 芒辉），可切换
- **黑名单**：支持群聊/用户级别过滤
- **模糊触发**：发送"炸了""卡了""崩了"等关键词自动回应当前状态

## 命令列表

| 命令 | 说明 |
|------|------|
| `/牛服` | 查询含"牛"的所有组 |
| `/鸽服` | 查询含"鸽"的所有组 |

| `/ip [组名]` | 查看服务器 IP 和端口 |
| `/详情 <服名或ID>` | 查看服务器详情卡片 |
| `/搜索 <关键词>` | 搜索全网服务器（图片结果） |
| `/查IP <IP>` | 按IP查服务器 |
| `/历史 [组名] [服名]` | 历史人数趋势图 |
| `/统计 [一天/一周/一月] [组名]` | 统计数据 |
| `/日志 [日期] [条数]` | 命令日志 |
| `/info [组名]` | 服务器信息（可加"图"渲染图片） |
| `/help` | 帮助 |

### 关键词触发

群聊绑定后，发以下词自动回复服务器状态：炸了 / 服务器炸了 / 炸服 / 卡了 / 连不上 / 宕机 / 崩了

## 配置文件

- `server_data.json` — 服务器列表、组配置、告警阈值等
- `toggle_state.json` — 各服务器启用/禁用状态
- `blacklist.json` — 黑名单
- `group_bindings.json` — 群聊与服务器组绑定
- `fuzzy_toggle.json` — 模糊匹配开关
- `group_noslash.json` — 无斜杠触发开关

## 示例

```
/添加服 牛 饭堂1 69724 饭堂一服

/查服 牛

--- 牛 状态 ---
==============
饭堂一服 12/50
==============

/搜索 插件            → 返回图片：全网含"插件"的服务器列表
/详情 59471           → 返回详情卡片
/搜索 芒辉 → 查到59471 → /详情 59471 → 完整卡片
```

## 注意

- 依赖 aiohttp + Pillow，AstrBot 自动安装
- 管理员权限基于 `data/cmd_config.json` 中的 `admins_id`
- 支持 aiocqhttp / qq_official / telegram 平台
- Telegram 需在 server_data.json 中配置 bot_token 和 chat_id

# 通用服务器查询框架 for AstrBot

> 支持动态组别、多服务器状态查询、IP端口映射、黑名单管理、历史趋势图等高级功能。

## 特色功能

- **动态组别**：实时增删服务器组，无需重启机器人
- **在线人数查询**：/查服 获取指定组内所有服务器的在线人数（支持数字自动排序）
- **IP端口映射**：/ip 获取服务器的公网连接地址
- **历史趋势图**：/历史 自动渲染 SVG 折线图，展示服务器在线人数变化趋势
- **错误日志**：/niulog 查询 fetch 失败记录，方便排查网络问题
- **黑名单系统**：支持群聊/用户级别的黑名单过滤
- **管理命令**：启停端口、修改服务器ID/名称、调整刷新间隔等
- **智能模糊提示**：当用户提到服务器名但未使用命令时，自动推送帮助信息
- **后台缓存**：自动轮询刷新数据，降低API压力

### 智能关键词触发

当群聊**已绑定**某个服务器组时，用户发送以下关键词，机器人会自动返回该组的在线状态：
- 炸了 / 服务器炸了 / 炸服 / 卡了 / 连不上 / 宕机 / 崩了

当群聊**未绑定**时，发送这些关键词会提示管理员进行绑定。

## 安装

1. 在 AstrBot 管理面板 -> 插件市场 -> 从 Git URL 安装：https://github.com/0720xxz/astrbot_plugin_niufu.git

2. 或手动下载解压到 addons/astrbot_plugin_niufu 目录，重启机器人。

## 使用方法

### 基础查询（所有人可用）

| 命令 | 说明 |
|------|------|
| /牛服 | 快捷查询含"牛"的所有组 |
| /鸽服 | 快捷查询含"鸽"的所有组 |
| /查服 <组名> | 查看指定服务器组的在线人数 |
| /ip [组名] | 查看服务器的 IP 和端口 |
| /历史 [组名] | 查看服务器在线人数历史趋势图（渲染为PNG图片） |
| /help | 显示帮助信息 |

### 管理员命令（仅管理员）

| 命令 | 说明 |
|------|------|
| /查看所有服 | 列出所有组别、服务器及启用状态 |
| /添加服 <组别> <识别名> <API_ID> <展示名> | 添加新服务器 |
| /删除服 <组别> <识别名> | 删除服务器 |
| /启用端口 <所有/组别> 或 /启用端口 <组别> <识别名> | 启用服务器(组) |
| /禁用端口 <所有/组别> 或 /禁用端口 <组别> <识别名> | 禁用服务器(组) |
| /黑名单 <添加群/删除群/添加人/删除人> <号码> | 群聊或用户级别黑名单 |
| /设置组头部文字 <组别> <第一行\|第二行\|分隔符> | 自定义输出头部文字 |
| /改服ID <组别> <识别名> <新ID> | 修改服务器API ID |
| /改服名 <组别> <识别名> <新展示名> | 修改服务器展示名称 |
| /改服组 <原组别> <识别名> <新组别> | 将服务器移动到其他组 |
| /调整刷新 <最小秒数> [最大秒数] | 动态轮询间隔（最小2秒） |
| /绑定组 <组名> | 将当前群绑定到指定服务器组 |
| /绑定组 <群号> <组名> | 将指定群绑定到服务器组（可在私聊使用） |
| /解绑组 [群号] | 解除群绑定 |
| /开启模糊匹配 [群号] | 开启当前群或指定群的触发词提示 |
| /关闭模糊匹配 [群号] | 关闭触发词提示 |
| /开启无斜杠 <组名> | 允许直接发送组名（不带/）查询 |
| /关闭无斜杠 <组名> | 禁止直接发送组名查询 |
| /niulog 或 /牛服日志 | 查看最近的服务器查询错误日志 |
| /清除日志 | 清空错误日志记录 |

## 配置文件

插件会在自身目录下自动生成以下配置文件：

- server_data.json – 服务器组、服务器列表、头部文字等配置
- toggle_state.json – 各服务器启用/禁用状态
- blacklist.json – 黑名单列表
- group_bindings.json – 群聊与服务器组绑定关系
- fuzzy_toggle.json – 模糊匹配开关
- group_noslash.json – 无斜杠触发开关

## 示例

/添加服 牛 饭堂1 69724 饭堂一服

/添加服 牛 饭堂2 69725 饭堂二服

/查服 牛

输出示例（按数字自动排序）：

--- 牛 状态 ---
==============
饭堂一服 12/50
饭堂二服 8/50
==============

群成员发送：饭堂一服炸了

机器人自动回复"牛"组的在线状态。

## 注意

- 插件依赖 aiohttp，AstrBot 会自动安装。
- 管理员权限基于 AstrBot 根目录下 data/cmd_config.json 中的 admins_id。
- 默认的 API 地址为 https://api.scplist.kr/api/servers/{id}，如需修改可在代码中替换。
- /历史 指令使用 AstrBot 内置 html_render 渲染，无需额外依赖。
